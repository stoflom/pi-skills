# pi-skills

Custom Pi coding agent skills.

## Skills

| Skill | Description |
|-------|-------------|
| [firefox-testing](firefox-testing/) | Automated web testing using Firefox and the Marionette protocol via Selenium and GeckoDriver. |
| [meld-compare](meld-compare/) | Visual file comparison using the Meld GUI tool. |
| [darktable](darktable/) | Develop raw images headlessly via darktable-mcp (MCP tools): standard 7-step pipeline, XMP sidecar decoding, masked AI sharpening, and export. Requires the `pi-mcp-extension` and a `darktable-mcp` server — see [darktable/README.md](darktable/README.md). |
