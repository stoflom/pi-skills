# pi-skills

Custom Pi coding agent skills.

## Skills

| Skill | Description |
|-------|-------------|
| [firefox-testing](firefox-testing/) | Automated web testing using Firefox and the Marionette protocol via Selenium and GeckoDriver. |
| [meld-compare](meld-compare/) | Visual file comparison using the Meld GUI tool. |
| [darktable](darktable/) | Develop raw images headlessly via darktable-mcp (MCP tools) or `darktable-cli`: standard 7-step pipeline, XMP sidecar auto-import, masked AI sharpening, tonal stats, and export. Includes a real XMP example file. Requires the `pi-mcp-extension` and a `darktable-mcp` server — see [darktable/README.md](darktable/README.md). |
